# BookBazaar

## Introduction

BookBazaar is an online bookstore where users can explore, purchase, and review books across various categories. The platform provides an intuitive and seamless shopping experience, allowing book lovers to find their favorite reads easily.

## Project Type

Frontend | Backend | FullStack

## Deployed App

Frontend: https://bookbazaar-online-book-store.vercel.app

Backend: https://book-bazaar-backend-yyf6.onrender.com/api


## Features

- Responsive and dynamic website
- User authentication using jwt
- Password hashing
- Add to Cart
- Product Checkout
- Orders list

## Installation & Getting started

Detailed instructions on how to install, configure, and get the project running.

To run the frontend website, enter the following commands in your terminal:

```bash

# Move into the FrontEnd Directory
cd e-commerce-frontend/

# Install all dependencies
npm install

# Run the dev server
npm run dev

```

To run the backend server, enter the following commands in your terminal:

```bash

# Move into the BackEnd directory
cd e-commerce-backend/

# Install all dependencies
npm install

# Run the server
npm run start

```
